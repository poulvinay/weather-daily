Map controls & shortcuts

Keyboard (map focus)

  • = / + : Increase zoom by 1
  • Shift+= / Shift+ + : Increase zoom by 2
  • - : Decrease zoom by 1
  • Shift+- : Decrease zoom by 2
  • Arrow keys: Pan by 100px
  • Shift+→ / Shift+← : Rotate by ±15°
  • Shift+↑ / Shift+↓ : Change pitch by ±10°
  • Shift+S : Jump to search bar
  • Shift+? : Open this help popup

Mouse / touch

  • Drag with left mouse: Pan the map
  • Scroll wheel / trackpad pinch: Zoom in or out
  • Right‑click + drag (or Ctrl/Cmd + drag): Rotate and tilt
  • Double‑click: Zoom in on clicked location
